A robot's pickup line for make.fun's "The Robot Pickup Line Championship" — one line, at most 200 characters, written for a robot to say out loud.

## Run it

```sh
node main.ts
```

The program writes the line to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set).
